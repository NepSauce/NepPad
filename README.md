# Nep Pad

A simple Java-based Notepad application that allows you to open, edit, save, and save files as `.txt`. This app provides a graphical user interface (GUI) built with Java Swing for easy use.

## Features
- **Open**: Opens existing `.txt` files.
- **Save**: Saves the current text in the editor to a file.
- **Save As**: Saves the current text to a new file.
- **Exit**: Closes the application.
